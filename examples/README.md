# Examples

Finished Motion Studio projects you can open, play with and render.

| Package | What it shows |
| --- | --- |
| *(coming soon)* | A short launch film made entirely with Motion Studio + Claude Code |

**To open one:** start the studio (`npm run dev`), click **Import package** on the dashboard and
choose the `.zip`. It becomes a new project in your library — nothing in this folder is modified.

**To share your own:** Render page → **Project package** → download the `.zip`.
